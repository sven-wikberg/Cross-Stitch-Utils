# Data

Ce dossier peut contenir des donnees utiles au projet, par exemple des palettes de fils ou des exemples de projets.

Ne pas y stocker de secrets, mots de passe ou tokens GitHub.

`builtin-progress.js` contient la sauvegarde integree unique de l'outil 3. Elle est versionnee dans Git et peut etre mise a jour par le bouton de synchronisation GitHub pour reprendre le meme projet depuis plusieurs machines.

## Exemple de test

`examples/trois-fleurs.pattern.json` est un petit pattern compatible avec l'etape 1 de l'outil 2 : 40 x 24 cases, 159 croix, DMC 321 (96 croix), 444 (27 croix) et 702 (36 croix). Deux fleurs sont proches, la troisieme est plus eloignee pour tester les coupes au seuil par defaut de 10 cases. L'apercu est dans `examples/trois-fleurs.png`. Aucun chemin n'est predefini.
