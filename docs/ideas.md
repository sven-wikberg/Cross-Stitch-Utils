# Idees d'outils

## Priorite 1

- Calculateur de taille de toile : entrees pour le nombre de points, le count de la toile et les marges.
- Calculateur de fils : liste de couleurs, estimation de longueur, suivi des bobines disponibles.
- Journal de projet : nom du projet, dimensions, toile, fils, date de debut, progression.

## Priorite 2

- Conversion image vers grille.
- Reduction de palette.
- Export PDF imprimable.
- Comparaison de couleurs entre marques de fils.
